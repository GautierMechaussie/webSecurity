# vuln-app

Application Flask volontairement vulnérable, réalisée pour le TP Sécurité web proactive (DevSecOps).

⚠️ Usage pédagogique uniquement. Ne jamais déployer sur un serveur accessible depuis Internet.

## Lancer en local

    python -m venv venv
    venv\Scripts\activate        (Windows)   ou   source venv/bin/activate   (Linux/Mac)
    pip install -r requirements.txt
    python app.py

Puis ouvrir http://127.0.0.1:5000
